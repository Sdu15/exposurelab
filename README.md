# Exposure Lab — Landing Prototype

V8 — Acid Yellow + Navy. Bold contemporary direction for the Exposure Lab agency site.

## Live

Deployed via Cloudflare Pages: `https://exposurelab-landing.pages.dev`

## Structure

- `index.html` — full single-page prototype. Google Fonts only, no build step.
- Self-contained, openable directly in a browser.

## Deploy

Cloudflare Pages connected to this repo. Push to `main` → auto-deploys.

## Direction

Acid yellow (`#f5d142`) accent on deep navy (`#0a1628`) base. Saira Stencil One for display, Space Grotesk for body. Strong CTAs upfront.
